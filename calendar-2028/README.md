# Календари на 2026, 2027 и 2028 годы

Статический календарь для 2026, 2027 и 2028 годов: одна HTML-страница, CSS-оформление и JavaScript, который строит все 12 месяцев выбранного года, выделяет праздничные дни России и открывает короткий мультфильм с музыкой по клику на праздник.

## Запуск локально

Из корня текущего репозитория:

```bash
python3 -m http.server 8080 --directory calendar-2028
```

Из папки `calendar-2028`:

```bash
python3 -m http.server 8080
```

Откройте страницу:

```text
http://localhost:8080
```

## Проверка

Из корня текущего репозитория:

```bash
node calendar-2028/calendar.test.mjs
```

Из папки `calendar-2028`:

```bash
npm test
```

Тест проверяет, что доступны 2026, 2027 и 2028 годы, 2028 год високосный, февраль и количество дней пересчитываются по выбранному году, список российских праздников содержит ожидаемые даты для каждого года, а у каждого праздника есть сценарий мультфильма и мелодия.

## Праздники России

В календаре для каждого доступного года выделены фиксированные официальные праздничные даты РФ без учета переносов выходных:

- 1-8 января — Новогодние каникулы и Рождество Христово
- 23 февраля — День защитника Отечества
- 8 марта — Международный женский день
- 1 мая — Праздник Весны и Труда
- 9 мая — День Победы
- 12 июня — День России
- 4 ноября — День народного единства

Нажмите на выделенную дату в календаре, чтобы открыть короткую анимированную сцену с синтезированной музыкой. Музыка создается Web Audio API прямо в браузере и не требует внешних аудиофайлов.

## Создание нового репозитория на GitHub

В этой среде GitHub CLI доступен только для чтения, поэтому создание репозитория нужно выполнить у себя локально или в веб-интерфейсе GitHub.

Вариант через GitHub CLI:

```bash
cp -R calendar-2028 ~/calendar-2028
cd ~/calendar-2028
git init
git add .
git commit -m "Add Russian holiday calendars"
gh repo create russian-holiday-calendars --public --source=. --remote=origin --push
```

Вариант через сайт GitHub:

1. Создайте новый репозиторий `russian-holiday-calendars`.
2. Скопируйте файлы из папки `calendar-2028` в локальную папку нового репозитория.
3. Выполните:

```bash
git add .
git commit -m "Add Russian holiday calendars"
git branch -M main
git remote add origin git@github.com:<ваш-логин>/russian-holiday-calendars.git
git push -u origin main
```
